## 一、FlexPendant 是什么

FlexPendant 是 ABB 机器人（IRC5 / OmniCore 控制器）的示教器，本质是 **"一块触摸屏 +
一套安全相关硬件按键"** 的组合设备。握住并操作它能完成：手动点动、示教记录、程序调试、
运行监控、报警诊断、参数修改。（来源：[ABB FlexPendant 产品手册 3HAC093167](https://search.abb.com/library/Download.aspx?DocumentID=3HAC093167-001)）

- **触摸屏（App Window）**：承载图形界面，负责显示与编辑、导航。
- **硬件按键区**：急停、使能开关、方向摇杆、功能软键、导航键。负责**安全**与**关键动作**。

> 一句话：触摸屏用于"看和编辑"，硬件按键用于"动和安全"。

## 二、UI 视觉层面

### 2.1 硬件按键区的视觉特征（Web 里要"演"出来的部分）

| 硬件 | 外观/位置 | 交互语义 |
|---|---|---|
| **急停按钮** | 红色蘑菇头，握把上方前端 | 立即停机；不是"暂停" |
| **使能开关（DEAD MAN）** | 握把背面，三段式（放开/中间/压到底） | 只有按到**中间档**才允许手动移动；压到底反而停 |
| **方向摇杆（Joystick）** | 握把上方拇指位，四向推动 | 推动方向 → 坐标轴 +/− 运动 |
| **启停/确认/取消** | 屏幕下方物理键 | 运行启动、确认对话框、返回 |
| **可编程功能键** | 屏幕右侧 4 个软键（标签随上下文变化） | 常用功能快捷键，可自定义 |

**视觉隐喻建议（Web）**：教学仿真无法复现真实硬件，但可用"使能提示条 + 摇杆方向
可视化 + 软键区"来还原"动之前必须使能、推动方向决定轴"的安全交互直觉。

### 2.2 触摸屏画面分区（App Window）

FlexPendant 触摸屏的画面不是一整块，而是**固定分区**，这是最值得参考的 UI 结构：

```
┌──────────────────────────────────────────────────────┐
│ ① 窗口标题栏（当前功能名 + 关闭/最小化）                 │
├──────────────────────────────────────────────────────┤
│                                                       │
│  ② 内容窗口（当前应用的主体内容区）                     │
│     - 列表 / 表格 / 编辑器 / 图形                      │
│                                                       │
├──────────────────────────────────────────────────────┤
│ ③ 快捷设置区 QuickSet（速度倍率、坐标系、任务名...）     │
├──────────────────────────────────────────────────────┤
│ ④ 底部状态栏（运行/停止、程序指针 PP、电机状态、急停灯）  │
└──────────────────────────────────────────────────────┘
```

| 分区 | 显示内容 | 本项目对应 |
|---|---|---|
| **① 窗口标题栏** | 当前功能名、窗口操作 | `WorkbenchLayout` 的 `dock-title` |
| **② 内容窗口** | 当前功能主体（列表/编辑器/图形） | 右侧功能面板 `dock-body` |
| **③ 快捷设置** | 速度倍率、当前坐标系、运动模式、任务 | 目前散落在 `CartesianControlPanel`，未集中 |
| **④ 底部状态栏** | 运行/停止、PP 指针、电机使能、报警灯 | `App.vue` 顶栏有 PP/MP 与状态 pill |

> 参考：状态栏显示运行状态、程序指针、速度倍率、坐标系等是 FlexPendant 的常态
> （[示教器基础认识](https://m.mgongkong.com/index.php?app=article&act=view&article_id=6484)）。

### 2.3 主菜单（App 网格）

- 点击屏幕左上/右上角的 **ABB 菜单键** 弹出主菜单，是所有功能的入口。
- FlexPendant 主菜单像手机桌面：**图标网格**，每项进一个功能应用。
- 常见项：**手动操纵、程序编辑器、程序数据、程序运行、输入输出、控制面板、报警与事件**。
- 屏幕通常还有 **4 个可编程功能键**（右侧），可自定义为"切换坐标系 / 打开程序编辑器 /
  显示输入输出"等快捷键，路径：主菜单 → 控制面板 → 配置 → 可编程按键。

> 本项目 `WorkbenchLayout` 的最右侧窄图标边栏（RAPID / 数据 / 控制）正是"主菜单/可编程
> 键"的 Web 形态，只是把 FlexPendant 屏幕**左侧**菜单放到了 Web 的**右侧**。

## 三、页面级功能

FlexPendant 的页面按"操作模式"串联。这里按功能页面维度列举，每页给出功能点。

### 3.1 操作模式（全局前置概念，非独立页面）

在屏幕左上角**钥匙图标**切换：
- **手动模式**：编程、调试、手动操纵。速度受限（通常 ≤250mm/s），必须按住使能开关。
- **自动模式**：程序自动连续运行，需满足安全互锁。

> 状态栏会随模式切换从"自动"变"手动"。这是 FlexPendant 一切交互的前提，
> 对本教学项目是很好的"安全教学"切入点。

### 3.2 【页面】手动操纵（Manual / Jog）

见第四节详述。功能点：操作模式选择、运动模式、坐标系、增量步进、摇杆方向、速度倍率。

### 3.3 【页面】程序编辑器（Program Editor）

- **层级结构**：任务 Task → 模块 Module → 程序 PROC / 功能 FUNC / 中断 TRAP。
- 以**指令行**为单位编辑，光标选中当前行。
- 常用功能点：插入指令、修改参数（目标点/速度/转弯区/工具/工件）、删除/注释、
  剪切/复制/粘贴、Change to MoveJ↔MoveL、撤销/重做。
- 每条运动指令可展开看到完整操作数（目标、速度、转弯区、工具、工件）。
- 左侧常带**行号/指针标记**（PP 程序指针、MP 运动指针）。

> 本项目 `ProgramWorkspace` / `RapidSourceEditor` / `ProgramEditorToolbar` 已实现
> 大部分：插入 MoveJ/MoveL、参数编辑器（目标/速度/转弯区）、剪切/复制/粘贴/注释、
> Change to MoveJ↔MoveL、撤销重做（3 步）。见"六、对照表"。

### 3.4 【页面】程序数据（Program Data）

- 浏览/新建/编辑所有程序数据类型：`robtarget`、`tooldata`、`wobjdata`、`speeddata`、
  `zonedata`、`loaddata`、`num`、`bool`、`string` 等。
- 每种类型有"新建"入口，新建时有默认值。
- 选择某条数据可查看/修改其字段（如 robtarget 的位置 trans + 姿态 rot）。

> 本项目 `ProgramDataPanel` 已按数据类型浏览六类运动记录与 num/bool 标量，声明来自
> 同一次 parser 结果（不建第二份点位存储，符合 `CLAUDE.md`）。

### 3.5 【页面】程序运行（Program Run / Testing）

- 从 PP（Program Pointer）开始运行，提供：**运行 Run、单步 Step、停止 Stop、PP to Main**。
- 显示 PP / MP 指针位置，可查看当前正在执行的指令行。
- 停止后可能要求 PP to Main 再运行。
- 单步：逐条指令执行，适合调试。

> 本项目 `ProgramControlPanel` 正是这一页面的 Web 实现，且按项目约束只保留
> 运行/单步/停止/PP to Main，不引入独立暂停/继续。

### 3.6 【页面】输入输出（Inputs / Outputs）

- 查看数字输入/输出（DI/DO）、模拟量、组信号的状态。
- 手动强制/模拟信号，用于测试互锁与逻辑。
- 常与夹具到位、门锁、真空 OK 等信号的监控。

> 本项目目前**无** IO 监控页面（业务上电信号非教学重点），如后续需要可作为扩展。

### 3.7 【页面】程序数据设置（工具/工件/负载）

常见设置流程（主菜单 → 程序数据 → 相应类型 → 新建）：
- **工具 tooldata**：tframe（工具坐标，四点法或直接输入偏移）、load、robhold。
- **工件 wobjdata**：三点法（原点 + X 方向点 + Y 方向点）定义工作平面。
- **有效载荷 loaddata**：mass 质量、cog 重心、inertia 惯性。

> 本项目 `MotionArgumentPanel` 已可在运动指令参数中补全目标点/速度/转弯区；
> Tool/WObj 目前不设选择器（靠源码手改），这属于明确的现状差异。

### 3.8 【页面】控制面板（Control Panel）

- 语言设置（中/英）、可编程按键配置、系统参数、速度/增量相关设置。
- 属工程师级配置，普通操作员不宜乱改。

### 3.9 【页面】报警与事件（Alarms / Events / Logs）

- 查看当前报警、历史报警、事件日志。
- 报警时第一时间看到报警内容与 IO / 程序指针状态。

> 本项目 `RunLogPanel` 承担运行日志/诊断的角色，未做"报警等级 + 历史"的完整形态。

## 四、手动操纵页面（与本校仿真最相关）

FlexPendant 手动操纵页是本项目 `JogControlTabs` 的直接原型，逐项列出：

### 4.1 操作模式
- **单轴（关节）模式**：逐个控制 J1–J6 轴，与坐标系无关；用于调整姿态、避开奇异点。
- **线性模式**：TCP 沿直线运动。
- **重定位模式**：TCP 位置不变，只改变工具姿态。

### 4.2 坐标系（线性/重定位模式下）
- **大地坐标系 (World)**：机器人安装基础坐标。
- **基座坐标系 (Base)**：底座中心为原点，多数基本选择。
- **工件坐标系 (Work Object)**：用户自定义工作平面。
- **工具坐标系 (Tool)**：以工具末端 (TCP) 为原点。

### 4.3 增量 / 步进
- 无增量（连续运动）、小/中/大增量。
  - 小增量：最慢、最精确（微调定位）。
  - 中/大增量：适中/常规速度。
  - 应用：精确定位用**小增量**，快速移动用**大增量或无增量**。

### 4.4 摇杆方向与锁定
- 推动摇杆 → 坐标轴 +/− 运动；幅度控制速度方向。
- **锁定功能**：摇杆"斜着走"产生不需要的运动分量时，按锁定键选择只锁水平/垂直/旋转分量。
- 移动前必须**按住使能开关**。

### 4.5 速度倍率
- 手动模式下速度倍率通常可调且受安全限制（≤250mm/s）。
- 是 FlexPendant 状态栏常驻显示项之一。

### 4.6 UI 呈现参考（真机）
- 主内容区显示当前关节角度 / TCP 位姿（X Y Z + Rx Ry Rz）。
- 顶部/一侧显示当前坐标系、运动模式、增量、速度倍率。
- 摇杆推动与画面坐标轴方向有明确映射。

## 五、程序编辑器 / 程序运行页面

### 5.1 程序编辑器 UI
- 以指令行为单位；行左侧是行号 + PP/MP 指针标记。
- 选中当前行后，底部/侧边出现**上下文软键/菜单**（添加、编辑参数、剪切/复制/粘贴/注释、
  Change to MoveJ↔MoveL）。
- 运动指令可展开显示操作数；参数可弹出选择器（目标点、速度表、转弯区表）。

### 5.2 程序运行 UI
- 顶部/状态栏显示运行状态、PP/MP 指针。
- 底部软键：**运行、单步、停止、PP to Main**。
- 当前执行到的指令行高亮。

> 对照结论：**功能层面**本项目已覆盖 FlexPendant 大部分核心页面；缺口主要在
> **"示教器外壳"的视觉隐喻**（统一状态栏、软键区、摇杆/使能/速度倍率的集中呈现）。

### 6.1 顶/底部状态栏的具体差距（针对"⚠️ 部分，未集中"的展开）

先说结论：本项目**有**顶栏（`App.vue` 的 56px topbar），也**有**相当多状态信息，
但它们**分散在多个组件里**，没有像 FlexPendant 那样"一条横贯的、常驻的状态条"
集中呈现。下面把 FlexPendant 状态栏应含的每一项，与实际分布逐条对比：

| FlexPendant 状态栏条目 | 本项目当前所在位置 | 状态 |
|---|---|---|
| **运行/停止状态**（RUNNING/STOPPED） | `ProgramControlPanel`：`stateLabel`（空闲/运行中/已停止/已完成/错误），带 `program-state-*` 类 | ⚠️ 有，但只在控制面板内；顶栏 `transport` 键组本身不显示状态文字 |
| **程序指针 PP** | `App.vue` 顶栏 pill：`PP {programPointer}`；`ProgramControlPanel` 也有读数 | ✅ 顶栏已有 |
| **运动指针 MP** | `App.vue` 顶栏 pill：`MP {motionPointer}` | ✅ 顶栏已有 |
| **速度倍率** | **无显式速度 UI**（`useMotion` 内部有速度限制，但无展示） | ⬜ 缺失 |
| **当前坐标系**（World/Base/Tool/Wobj） | `CartesianControlPanel` 内的坐标系选择器 | ⚠️ 有，但在 Jog 面板内，不在常驻状态条 |
| **运动模式**（单轴/线性/重定位） | `JogControlTabs` 的 joint/cartesian 两个 tab | ⚠️ 有，但只有两档（关节/笛卡尔），无"重定位"独立档 |
| **关节角度 / TCP 位姿** | `PoseReadout`（场景右下角角标）+ `CoordinateInfoPanel` + `JointControlPanel` | ⚠️ 有，但分散在面板与角标 |
| **电机使能状态** | 无（Web 无使能开关概念） | ⬜ 缺失（可选教学隐喻） |
| **急停/报警灯** | `App.vue` 顶栏场景状态 pill（loading/error/ready）有圆点变色 | ⚠️ 部分，只反映场景加载，不反映运行报警 |

**"未集中"的关键含义**：
1. **没有一条横贯的常驻状态条**——FlexPendant 的状态信息在屏幕底部固定一条、
   随时可见；本项目信息散落在顶栏、各个功能面板、场景角标里，跳到哪个功能才看得到哪块。
2. **速度倍率缺失**——真机状态栏常驻显示并可调，本项目完全没有 UI 呈现。
3. **坐标系 / 运动模式 / 位姿不常驻**——真机在 Jog 时状态栏常驻坐标系与模式；
   本项目需要在 Jog 面板里才看得到。
4. **运行状态文字不在顶栏**——`transport` 键组只有按钮，状态用 enabled/disabled 隐式表达，
   无显式"运行中/已停止"文字（该文字在面板内 `stateLabel`）。

> 若要做"朝向 FlexPendant 的顶/底部状态栏"，最小且高价值的做法是：在现有顶栏（或底部）
> 加一条**常驻状态条**，集中显示 运行状态 + 坐标系 + （可选）速度倍率，把分散的信息
> 收拢、并新增速度倍率这一缺失项。这与 `CLAUDE.md` 的最简实现承诺一致，且保持单一职责。
