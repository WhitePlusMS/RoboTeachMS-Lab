## 验收门槛

资产只有同时满足以下条件，才能从“候选”改为“可用”：

1. 文件名、CAD 属性或 ABB 机制文件明确写出 `IRB 1200-5/0.9`，且与参数来源属于同一代际、同一保护配置。[S03]
2. 原始文件和转换结果的教育展示、转换、线上再分发权得到确认。[S08][S09]
3. 可解析出 `root/base -> J1 -> J2 -> J3 -> J4 -> J5 -> J6 -> flange` 的独立层级，并为每个关节记录局部旋转轴和零位。
4. 单位和比例通过官方 `0.9 m / R=901 mm`、主要尺寸图和包围盒实测交叉核验。[S03]
5. Three.js GLTFLoader 可以加载，且 J1-J6 逐轴正负方向、范围、基座零位、法兰朝向均能与同型号机制/参数解释一致。
6. 若上述任一项缺失，资产清单必须保持“未确认”，不能用空节点、手工缩放、改符号或第三方 DH 表掩盖缺口。
