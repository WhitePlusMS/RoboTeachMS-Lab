## 任务目标

为 ABB-Robot-Programming-Lab 的首期 ABB IRB 1200 教学仿真建立一份可追溯的“模型 + 参数”资产基准。

本任务只做联网检索、资料核验和结果整理，不修改 src、不改 package.json、不替换当前 KUKA 模型，也不自行猜测缺失参数。

最终要回答两个问题：

1. 哪一个 ABB IRB 1200 具体变体适合首期教学仿真？
2. 该变体是否有可以合法用于纯前端展示和运动驱动的三维模型，以及与它严格对应的运动学参数？

## 重要边界

- 不能把“搜索到的图片”当成可驱动的三维模型。
- 不能把 CAD 外形尺寸当成 DH 参数。
- 不能把不同变体的模型和参数拼在一起。
- 找不到官方参数时必须明确写“未找到”，不能用博客、论坛或经验值补齐。
- 第三方模型只能作为线索；没有清晰授权时不能作为项目资产。
- 不要为了得到一个文件而绕过 ABB 登录、下载限制、软件授权或站点访问控制。
- 不要把 RobotStudio 的内部资源直接打包进网页，除非来源条款明确允许这种再分发。
- 如果必须由项目负责人提供模型或资料，输出阻塞项，不要自行做决定。

## 检索顺序

优先使用一手来源，并在结果中记录完整页面标题、URL、访问日期和来源组织。

### 第一优先级：ABB 官方来源

检索以下官方域名和产品入口：

- ABB Robotics 产品页与机器人目录：abb.com、new.abb.com
- ABB Robotics 客户/产品门户：one.robotics.abb.com
- ABB 官方文档库：library.e.abb.com
- ABB RobotStudio、RobotWare、RobotStudio Library 的官方说明、产品规格和发布说明

建议同时使用中英文关键词：

- ABB IRB 1200 CAD model
- ABB IRB 1200 STEP
- ABB IRB 1200 5/0.9
- ABB IRB 1200 7/0.7
- ABB IRB 1200 product specification
- ABB IRB 1200 operating manual
- ABB IRB 1200 robot library RobotStudio
- ABB IRB 1200 joint limits
- ABB IRB 1200 kinematic parameters
- ABB IRB 1200 DH parameters
- ABB IRB 1200 Next Generation
- ABB IRB 1200 Hygienic

搜索时要区分旧款、Hygienic、Next Generation/Gen 2 和 Lite+ 等家族，不能只按“IRB 1200”四个字认定为同一个机器人。

### 第二优先级：官方软件/库的可用性核验

如果 ABB 官方资料说明模型通过 RobotStudio 或官方机器人库提供，需要确认：

- 是否能合法导出或引用到独立 Web 前端；
- 可获得的文件究竟是网格、CAD 实体、RobotStudio 专有资源还是完整站点；
- 是否包含六轴层级、旋转轴、法兰和基座信息；
- 再分发和教育演示是否受许可限制；
- 是否需要用户自行从已授权的 RobotStudio 安装中导出。

如果只能在 RobotStudio 内部使用，必须把它记录为“参考/获取渠道”，不能直接宣称已经获得 Web 可用模型。

### 第三优先级：第三方来源

第三方 CAD/模型站点只用于发现候选，不作为最终事实来源。只有同时满足以下条件才可以列入候选：

- 明确标注具体 ABB IRB 1200 变体；
- 文件有可下载的实际几何，而不是预览图；
- 授权允许教育展示、转换和项目内使用；
- 模型的单位、比例、坐标方向和关节层级可核验；
- 能与 ABB 官方型号资料逐项比对。

如果许可证不清晰，标记为“不可直接使用”。

## “前端可用模型”的判定标准

模型必须从视觉和运动两方面可用，不能只看文件能否打开。

### 最低文件要求

优先级从高到低：

1. GLB/GLTF，且包含可驱动的关节层级；
2. STEP/IGES/OBJ/FBX 等可转换格式，且能在不改变比例和层级语义的情况下转换；
3. 只有图片、单体网格或无法确认层级的 CAD，不算首期可用模型。

### 必须核验的结构

- 基座是否固定为独立根节点；
- J1 到 J6 是否各有明确的旋转节点；
- 六个轴的旋转方向和零位是否可解释；
- 末端法兰/工具安装面是否存在；
- 模型单位和尺寸是否正确；
- 转换为 GLB 后是否保留节点名称、父子层级、局部变换和材质；
- 是否存在多余的碰撞体、外部纹理或运行时无法加载的依赖；
- 在浏览器 Three.js 中是否能稳定加载，而不是只在桌面 CAD 软件中打开。

建议目标文件名为：

ABB_IRB1200_<明确变体>_source.<原格式>
ABB_IRB1200_<明确变体>.glb

但本任务不要直接把大模型提交到仓库，除非负责人另行确认授权和仓库容量。

## 必须收集的参数

对于选定的单一变体，按下表逐项寻找。每一项都必须带来源或明确标记为未知。

### 型号与能力

- 完整型号和变体后缀；
- 负载；
- 最大工作范围/臂展；
- 安装方式；
- 防护等级或 Hygienic 版本标识；
- 对应控制器/RobotWare 版本（如果资料中有）。

### 运动学与关节限制

- 轴数和轴顺序；
- 每个关节的最小角度、最大角度；
- 每个关节的正方向；
- 机械零位/校准零位；
- 关节最大速度（如果教学规划需要）；
- 轴长、偏置、法兰尺寸或等价的官方几何参数；
- DH、MDH、URDF 或其他明确的刚体变换数据。

注意：如果官方没有公开 DH 表，可以记录“官方未公开 DH”，再寻找官方 CAD、RobotStudio 参数或厂家资料中可验证的等价变换。不得从网上抄一张未标注变体的 DH 表。

### 坐标与姿态

- ABB 基坐标的原点和轴方向；
- 机械臂法兰坐标的原点和轴方向；
- 工具坐标（tool0/TCP）的默认定义；
- 姿态使用哪一种表示，是否出现四元数、旋转矩阵或 ABB 专用姿态结构；
- 长度单位、角度单位和速度单位；
- ABB 资料中的坐标约定如何映射到本项目的内部约定。

当前前端基线使用毫米、角度和六轴关节状态；研究结果要单独写出“来源单位”和“项目内部单位”，不能混写。

## 参数与模型的对应关系核验

至少完成以下交叉检查：

1. 模型文件名、官方型号和参数表中的型号完全一致。
2. 模型整体包围盒尺寸与官方臂展/主要尺寸数量级一致。
3. 每个关节节点的旋转轴方向与参数表正方向一致。
4. 基座零位和末端法兰方向能在三维场景中复现。
5. 用一组简单关节姿态做正解时，模型末端位置与参数模型没有明显尺度或轴向错误。
6. 如果模型与参数不一致，优先保留证据并报告冲突，不要通过任意缩放、换轴或改符号“调到看起来能动”。

## 完成判定

只有同时满足下面条件，任务才算完成：

- 具体变体已经明确，或明确列出需要负责人选择的变体；
- 至少找到一个模型候选，并确认它是否能合法用于前端；
- 模型与参数来自同一变体；
- 关节范围、轴顺序、坐标方向、单位和缺失项均已记录；
- 所有事实都有来源链接；
- 没有把未知参数伪装成已确认参数；
- 没有修改业务源码、依赖和场景控制逻辑。

如果官方资料不足，正确结果是输出“不足项和阻塞项”，而不是强行给出一套数字。
